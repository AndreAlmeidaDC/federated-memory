# Hipóteses

Afirmações do whitepaper e do guia que ainda não foram validadas empiricamente. Cada hipótese é um arquivo com: id (HYP-NNN), enunciado, como seria validada, status (open, testing, validated, refuted) e link para o experimento quando houver. Hipótese validada vira parte do texto principal. Hipótese refutada gera correção nos documentos, como aconteceu com o policy engine na v3.
